# Article Native Translation — 信达雅

A skill for personal AI agents: translate a long-form article (blog post, newsletter, essay, X Article, 公众号-style article) from **any source language** into one or more target languages so it reads as if it were written in that language by the same author.

**信达雅** — faithful in substance, idiomatic in form, elegant in effect:

- Keeps about 98% of the content: logic, structure, examples, opinions, tone
- Adapts about 2%: phrasing, idioms, metaphors and culture-bound references, localized to the target reader's culture (with a swap list the author can approve or revert)
- Paragraph-by-paragraph fidelity check, native-reader pass, names/numbers/links verification
- Optional short social-post versions per language
- Never publishes without the author's explicit approval

## Use

Give the `SKILL.md` in this repo to your personal agent (Muse, Claude Code, Codex, OpenClaw, …) as a skill, then ask it to translate an article and name the target language(s).
